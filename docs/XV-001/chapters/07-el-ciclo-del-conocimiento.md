# El ciclo del conocimiento

Una contribución puede comenzar como pregunta o hipótesis, avanzar hacia un proyecto, producir resultados, recibir críticas, corregirse y dar lugar a nuevos trabajos.

Xientia buscará preservar esas relaciones sin imponer un único recorrido a todas las disciplinas. Las versiones, las correcciones y las retractaciones deberán permanecer identificables, respetando restricciones justificadas de acceso.
