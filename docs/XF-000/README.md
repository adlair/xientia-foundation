# XF-000 — Constitución de Xientia

## Propósito

Establecer los fundamentos filosóficos, científicos, éticos e institucionales
que deberán orientar todas las decisiones de Xientia.

La Constitución no describe tecnologías concretas ni procedimientos operativos.
Define aquello en lo que Xientia cree, aquello que protege y los límites que no
deberá cruzar.
