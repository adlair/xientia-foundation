# Contribución a la Biblioteca Fundacional

Toda contribución deberá:

1. Respetar los principios fundacionales de Xientia.
2. Utilizar formatos abiertos y texto plano cuando sea posible.
3. Mantener trazabilidad mediante Git.
4. Evitar duplicar contenido que ya tenga una fuente canónica.
5. Identificar claramente cambios filosóficos, editoriales o normativos.
6. Conservar el historial de versiones.
7. Incluir justificación para cualquier modificación sustantiva.

Ningún principio constitucional deberá modificarse únicamente por conveniencia
comercial, política o tecnológica.
