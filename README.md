# Biblioteca Fundacional de Xientia

Este repositorio contiene los documentos fundacionales que definen la
identidad, los principios, la visión, la arquitectura, el modelo institucional
y la estrategia de desarrollo de Xientia.

Xientia se concibe como una infraestructura científica abierta orientada a
preservar, verificar, reproducir, conectar y compartir el conocimiento de
manera responsable.

> **Lema:** El conocimiento debe ser libre.

> **Principio rector:** La ciencia progresa cuando el conocimiento puede
> preservarse, verificarse, reproducirse y compartirse de manera responsable.

## Fuente oficial

El contenido canónico se mantiene en Markdown y se versiona mediante Git.

Los formatos ODT, PDF, HTML, EPUB y DOCX son productos derivados de publicación.
ODT y PDF serán los formatos institucionales preferidos para distribución.

## Principios tecnológicos

- Software libre y de código abierto siempre que sea técnicamente viable.
- Estándares y formatos abiertos.
- Independencia de proveedores.
- Interoperabilidad.
- Preservación de largo plazo.
- Trazabilidad integral.
- Automatización reproducible.
