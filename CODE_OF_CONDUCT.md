# Código de Conducta

La comunidad de Xientia se compromete a mantener un entorno profesional,
respetuoso, plural y basado en la evidencia.

No se tolerarán:

- discriminación;
- hostigamiento;
- falsificación de evidencia;
- plagio;
- suplantación;
- manipulación deliberada de procesos científicos;
- ataques personales;
- conflictos de interés ocultos.

El desacuerdo científico deberá expresarse mediante argumentos, evidencia y
respeto por las personas participantes.
